# 极简个税功能推进清单

## 1. 文档定位

本文档记录 P0 至 P3 的实现进度、后续功能顺序和默认决策。每完成一个独立功能点后，应运行校验并单独提交 commit。

## 2. 推进原则

- 每个功能点独立交付、独立提交，避免多个不相关改动混在一起。
- 计算逻辑优先抽到 `app/src/lib/`，页面只负责输入、展示和交互。
- 税法、社保、公积金规则必须保留规则年份、核对日期和来源入口。
- 页面先解决真实计算问题，再补 SEO 内容；SEO 文案不能承诺尚未实现的能力。
- 移动端按主要使用场景验收，尤其是表单、结果卡、弹框和表格。

- 全年逐月明细。
- 个人所得税税率表页面，支持综合所得和分类所得分层查看。
- 专项附加扣除选择弹框和专项附加扣除独立页。
- 金额输入框位数提示与金额展示格式配置。
- 响应式导航和移动端抽屉菜单。
- 工资薪金固定测试样例：税率临界点、年中入职、社保和公积金基数不同、公积金比例、专项附加扣除、城市切换和基数范围。

## 7. P3 已完成

- 内容系统与规则后台边界已落到技术架构：Payload 管理文章、FAQ、城市 SEO、政策来源和规则草稿；计算公式仍保留在 TypeScript 领域模块。
- 规则采集审核流程已明确：采集脚本只生成草稿和导入任务记录，人工核对后才允许发布为有效规则。
- 前端读取策略已明确：优先读取 Payload 有效规则，失败时回退本地兜底规则，并展示实际规则版本和核对日期。
- Payload 规则集合已扩展：税率规则和专项附加扣除规则可以在后台维护年度、生效期、来源、警告、原始数据和业务状态。
- SEO 专题入口页已完成：覆盖年中入职、年底个税变高、工资档位、城市工资到手和不同所得类型案例入口。
- 年终奖临界点图表已完成：跨过税率临界点时，在结果中展示当前金额和建议金额的税前、到手对比。
- 工资薪金导出能力已完成：全年预扣逐月明细支持导出 CSV，便于用户核对或继续处理。
- 当月工资条导出能力已完成：工资薪金结果支持复制工资条，五险一金汇缴明细支持导出 CSV。
- 年终奖和长尾计算器导出能力已完成：年终奖、劳务报酬、稿酬、特许权使用费、经营所得、财产租赁、财产转让、利息股息红利、偶然所得支持导出 CSV。
- 可观测性基础事件已完成：提供通用 trackEvent，记录页面访问、工资计算、年终奖计算、结果展开、复制分享、导出 CSV、首页/专题/长尾入口点击。
- 工资薪金全年个税走势图已完成：在逐月明细上方展示全年预扣合计、最高月个税、首次跨档月份和 12 个月税额柱状图。
- 五险一金缴费占比图已完成：在汇缴明细上方展示本月汇缴总额，以及个人社保、个人公积金、企业社保、企业公积金的占比分布。
- 可观测性关键交互已补齐：记录金额分组切换、移动端菜单开关、税率表 tab 切换、专项附加扣除弹框打开、展开、选择、清空和保存。
- 统计服务可配置接入已完成：支持通过 `NEXT_PUBLIC_GTM_ID` 加载 GTM，通过 `NEXT_PUBLIC_PLAUSIBLE_DOMAIN` 加载 Plausible；统一事件会同时推送到 `dataLayer` 和 `window.plausible`。
- 城市规则覆盖状态已完成：城市索引页展示已收录城市、当年规则、已配置来源和来源待补数量，城市卡片显示规则生效日期和来源配置状态。
- 城市规则导入校验已完成：采集 JSON schema 已抽到公共模块，新增 `rules:validate` 离线校验命令和示例数据，导入前可先检查结构与关键字段。
- 城市规则审计命令已完成：新增 `rules:audit`，用于检查兜底城市规则的基数范围、缴费项目、来源和公积金比例配置。

## 8. P3 规划

1. 更多可解释图表：后续只补充真实高频使用场景中的解释型图表。
2. 更多导出能力：后续根据真实使用场景补充 PDF 或图片导出。
3. 更多可观测性：上线前确认最终统计服务和生产环境变量。

## 9. 默认决策记录

- “直接输入总额”适合作为快速模式，但不能和逐项选择结果混在一起展示。
- 专项附加扣除选择弹框使用公共弹框组件，扣除项选择器使用公共业务组件。
- 年终奖临界点只在结果区提示，不在输入时打扰。
- 分类所得不区分居民和非居民身份；综合所得先选所得类型，再在所得类型内切换居民或非居民。
- 对未实现的功能页面，首页可以保留入口，但必须明确“即将上线”或进入已实现的规则说明页。
