# 个人所得税计算规则与数据口径

## 1. 文档定位

本文档是计算引擎和内容页面共同使用的规则说明。产品总范围见：[极简个税产品需求文档](./personal-income-tax-product-requirements.md)。

规则核对日期：2026-07-27。

结果仅供测算，最终以个人所得税 APP、扣缴单位或税务机关口径为准。规则更新时应新增版本，不覆盖历史版本。

## 2. 工资薪金：累计预扣预缴

居民个人取得工资、薪金所得时，默认采用累计预扣法。

### 2.1 累计应纳税所得额

```text
累计预扣预缴应纳税所得额
= 累计收入 - 累计免税收入 - 累计减除费用
  - 累计专项扣除 - 累计专项附加扣除 - 累计依法确定的其他扣除
```

其中，累计减除费用通常按 `5,000 元 × 截至本月在本单位的任职受雇月份数` 计算。产品必须把“本单位任职月份数”和“自然年度月份”区分开。

### 2.2 本期应预扣预缴税额

```text
本期应预扣预缴税额
= (累计应纳税所得额 × 预扣率 - 速算扣除数)
  - 累计减免税额 - 累计已预扣预缴税额
```

计算结果低于 0 时，本期应预扣预缴税额按 0 展示；如业务场景存在退补税或更复杂的申报调整，应单独建模，不在基础工资计算器中猜测。

### 2.3 工资薪金预扣率表一

| 累计预扣预缴应纳税所得额 | 预扣率 | 速算扣除数 |
| --- | ---: | ---: |
| 不超过 36,000 元 | 3% | 0 |
| 超过 36,000 元至 144,000 元 | 10% | 2,520 |
| 超过 144,000 元至 300,000 元 | 20% | 16,920 |
| 超过 300,000 元至 420,000 元 | 25% | 31,920 |
| 超过 420,000 元至 660,000 元 | 30% | 52,920 |
| 超过 660,000 元至 960,000 元 | 35% | 85,920 |
| 超过 960,000 元 | 45% | 181,920 |

预扣率表一来源于国家税务总局关于累计预扣法的公开说明和 12366 个人所得税预扣率表。实现时应将税率表作为版本化数据，不要散落在多个前端页面中。

## 3. 专项附加扣除

当前已核对的标准包括：

| 项目 | 标准 |
| --- | --- |
| 3 岁以下婴幼儿照护 | 每个婴幼儿每月 2,000 元 |
| 子女教育 | 每个子女每月 2,000 元 |
| 赡养老人 | 每月 3,000 元；非独生子女分摊时每人不超过 1,500 元 |

其他专项附加扣除项目，如住房租金、住房贷款利息、继续教育、大病医疗等，应按政策版本配置，并保留城市、家庭关系、扣除比例和年度范围等条件。

父母对子女教育或婴幼儿照护的分配方式可能为一方 100% 或双方各 50%，输入模型需要表达扣除比例，不能只用一个布尔值。

## 4. 年中首次取得工资

“年度中间首次取得工资薪金”的场景需要单独处理。用户输入应至少包含：

- 在本单位首次取得工资的月份。
- 当年此前是否已经在其他单位按累计预扣法预扣过工资薪金或连续性劳务报酬所得。
- 是否符合按照截至本月月份数计算累计减除费用的条件。

若用户无法确认，产品应提供“按本单位实际任职月份估算”的默认选项，并用说明提示该选择会影响结果。

## 5. 其他所得类型的规则边界

这些类型不应直接复用工资薪金累计预扣公式：

| 所得类型 | MVP 状态 | 规则要求 |
| --- | --- | --- |
| 劳务报酬 | P2 | 按次或按月预扣，费用扣除和预扣率表二单独处理 |
| 稿酬 | P2 | 收入额按规定减除费用后，再按稿酬规则处理 |
| 特许权使用费 | P2 | 按次或按月预扣，不能套工资薪金公式 |
| 财产租赁 | P2 | 费用、修缮和税费扣除条件需要单独输入或说明 |
| 财产转让 | P2 | 以收入减财产原值和合理费用后的余额为基础 |
| 利息股息红利、偶然所得 | P2 | 通常按次计算，适用规则和税率单独维护 |
| 年终奖 | P1 | 单独计税与并入综合所得对比，政策有效期版本化 |

## 6. 数据模型最低要求

每条规则至少保存：

- `ruleType`：工资薪金、专项附加扣除、年终奖或其他所得类型。
- `effectiveFrom`、`effectiveTo`：生效区间。
- `sourceUrl`、`sourceTitle`：官方或可信政策来源。
- `checkedAt`：最近核对日期。
- `status`：草稿、生效、归档。
- `remark`：适用范围、例外条件和待确认事项。

计算输出建议保存规则版本 ID，以便后续复核“当时为什么得到这个结果”。

## 7. 测试样例要求

至少覆盖以下案例：

1. 月薪 8,000 元、无专项附加扣除，全年税率不跨档。
2. 月薪 20,000 元，累计应纳税所得额从 3% 跨入 10%。
3. 8 月入职，比较按本单位任职月份数和按自然年度月份数的差异。
4. 子女教育按 100% 扣除、双方各 50% 扣除。
5. 赡养老人独生子女和非独生子女分摊。
6. 年终奖单独计税与并入综合所得的差异。
7. 社保公积金基数低于下限、高于上限和手动覆盖。
8. 劳务报酬与工资薪金使用同一金额时，确认两种所得类型不复用同一公式。
